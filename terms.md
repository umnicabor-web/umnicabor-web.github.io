# Условия использования

Обновлено 10 октября 2026 года. Market Autopilot — локальное приложение для управления собственными каналами владельца. Оно не является продуктом Google, YouTube, VK или Яндекса.

Владелец предоставляет доступ только к своим аккаунтам или аккаунтам, которыми вправе управлять. Перед отправкой он проверяет материал, получателя, права на видео/изображения/звук, аудиторию, рекламный характер и необходимые разрешения. Факты, отзывы и доходы нельзя выдумывать. Соблюдаются правила каждой платформы; доступность API не означает юридическую допустимость любого материала.

В пилоте реальные отправки согласуются отдельно. Полностью автономный режим включается только после приёмки и явного согласия владельца в установленных пределах. Расходы внешних ИИ-сервисов на пилоте ограничены 300 рублями в месяц; текущая версия не выполняет платные ИИ-запросы. Приложение не гарантирует доход, количество просмотров или принятие материала платформой.

Режим DRY_RUN запрещает реальную отправку и платные запросы. Явная команда чтения статистики может обращаться к официальным API без изменения этого режима. Остановка местной очереди не отменяет материалы, уже переданные платформе: ими управляют в её кабинете. API может ограничивать квоты, задерживать данные или требовать повторную авторизацию.

Текущая версия проходит пилот. До завершения живых проверок публичного расписания и запуска после перезагрузки постоянная автономная работа не подтверждается. Владелец может остановить использование, отозвать доступ Google и удалить локальные данные согласно [политике конфиденциальности](privacy.html).
