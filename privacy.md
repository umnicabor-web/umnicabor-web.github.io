# Политика конфиденциальности

Обновлено 10 октября 2026 года. Эта страница описывает текущее локальное приложение Market Autopilot для владельца каналов.

## Доступ и назначение

Приложение запрашивает `youtube.upload`, `youtube.readonly` и `yt-analytics.readonly`. Они используются для согласованной загрузки видео, проверки правильного канала, чтения счётчиков и агрегированных отчётов. Оно обрабатывает ID каналов/видео, заголовки, описания, выбранные файлы, время публикации, данные просмотров, просмотра, подписчиков и доступные агрегаты аудитории. Доступ к почте, контактам и Google Drive не запрашивается.

## Хранение и передача

Очередь, отчёты и журнал находятся в SQLite на компьютере владельца. Копии SQLite хранятся локально и содержат историю операций и отчёты. OAuth-токены сохраняются отдельно в Windows Credential Manager; файл OAuth-клиента находится в защищённой локальной папке вне исходного кода. При явной настройке владельцем секреты могут читаться из переменных окружения. Токены не помещаются в SQLite, исходный код или журнал приложения.

Для работы с YouTube запросы и согласованные видео/метаданные отправляются в официальные сервисы Google по HTTPS. Google обрабатывает их по своим правилам. Выгрузка CSV сохраняется в выбранную владельцем локальную папку. Дополнительный Telegram-бот, если владелец его подключит, передаёт отчёты управления в Telegram только разрешённым ID; его настройка выполняется отдельно. Статистика не продаётся, не применяется для рекламы другим пользователям и не используется приложением для обучения моделей ИИ. Текущая версия не отправляет данные Google во внешние ИИ-сервисы.

Страницы документации не содержат собственных счётчиков или форм сбора данных. При размещении на GitHub Pages инфраструктура GitHub может журналировать обращения и IP-адреса согласно [правилам GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Контроль и удаление

Владелец может отозвать доступ Market Autopilot на [странице связанных приложений Google](https://myaccount.google.com/connections). Это не удаляет видео, уже сохранённые в YouTube: ими управляют отдельно в YouTube Studio. Местные отчёты, файлы, SQLite и резервные копии сохраняются до удаления владельцем. Секреты удаляются отдельно из Windows Credential Manager или настроенных переменных окружения. Для полного удаления данных требуется удалить также экспортированные отчёты и резервные копии; удаление только текущей базы не удаляет её копии.

Использование полученных от Google API данных ограничивается назначением приложения и требованиями [Google API Services User Data Policy, включая Limited Use](https://developers.google.com/terms/api-services-user-data-policy). Изменение доступа или назначения требует обновления этой страницы и необходимого согласия владельца.
