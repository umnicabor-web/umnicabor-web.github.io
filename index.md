# Market Autopilot

Локальное Windows-приложение для владельца YouTube-каналов «Ирмар» и «Ого, находка!». Приложение готовит заголовки и описания из проверенных заметок, хранит очередь видео в SQLite и получает статистику официальных YouTube Data API и YouTube Analytics API. Каналы подключаются отдельно; перед загрузкой проверяется ID получателя.

В пилоте доступ предоставляется только владельцем. Каждая реальная отправка предварительно согласуется; режим DRY_RUN блокирует отправку и платные запросы. Получение статистики по явной команде не включает публикации. Результаты операций и дата получения отчётов доступны в локальном журнале. Приложение не определяет личности всех зрителей.

Автономный запуск допускается после успешных проверок доступов, публикаций, расписания, перезагрузки, прав и юридических условий. Пилот пока не прошёл всю приёмку. Доступ к аккаунту можно отозвать в настройках Google.
